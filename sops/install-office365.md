# Installing Microsoft Office 365 on a User Device

## Purpose
This SOP details how to install Office 365 on a Windows device using the Microsoft 365 account portal.

## Prerequisites
- Valid Microsoft 365 license assigned to the user
- Administrative rights on the target device

## Steps

1. Sign in to the user's account at: [https://portal.office.com](https://portal.office.com)
2. On the main dashboard, click **Install Office**
3. Select **Office 365 apps** to download the installer
4. Run the downloaded installer (.exe file)
5. Follow on-screen prompts to complete installation
6. After installation, open any Office app (e.g., Word)
7. Sign in using the user's Microsoft 365 credentials to activate the license
8. Confirm activation by checking the account info under **File > Account**
9. Apply any available Office updates:  
   - Open an Office app  
   - Go to **File > Account > Update Options > Update Now**

## Notes
- Restart may be required post-install
- Verify Outlook profiles if migrating from previous installs
