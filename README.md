# tech-support-toolkit

This project simulates an entry-level IT support environment through standardized documentation and scripting tools. It is intended to demonstrate technical readiness for helpdesk, computer technician, or IT operations roles.

# Contents

# /sops/
Markdown-based Standard Operating Procedures (SOPs) for common IT tasks:
- Password resets via Microsoft 365 Admin Center
- Microsoft Office 365 installation and activation
- New user onboarding including account creation and workstation setup

# /powershell/
Basic PowerShell scripts designed for technician-level troubleshooting:
- Disk usage inspection using `Get-PSDrive`
- Application deployment using Winget

# Purpose

This toolkit was created to replicate real-world Tier 1 support responsibilities. It emphasizes process documentation, basic automation, and familiarity with remote system administration tools used in environments such as Microsoft 365 and Windows-based infrastructure.

# Tools Used

- Microsoft 365 Admin Center
- PowerShell (Windows Terminal)
- Winget package manager
- Markdown for SOP documentation

# Status

Core SOPs and PowerShell tools completed. Visual enhancements and workflow examples may be added in future updates.
