# New User Onboarding (IT Setup)

## Purpose
This SOP guides the setup process for onboarding a new employee from an IT perspective.

## Prerequisites
- Employment start date confirmed
- Request received for account creation and equipment allocation

## Steps

### Account Setup

1. Sign in to the Microsoft 365 Admin Center
2. Go to **Users > Active Users > Add a user**
3. Fill out the required details:
   - First/last name
   - Display name
   - Username/email
4. Assign a Microsoft 365 license (e.g., Microsoft 365 Business Standard)
5. Set location (e.g., Canada)
6. Set temporary password and require password change on first login
7. Assign groups or roles as requested (e.g., Distribution Lists)

### Device Setup

1. Prepare a clean workstation or laptop
2. Install Windows updates and security patches
3. Install standard software:
   - Microsoft Office 365
   - Google Chrome
   - VPN client (if applicable)
   - Endpoint protection (e.g., Microsoft Defender or Sophos)
4. Join the device to Azure AD (if applicable) or configure local profile

### Finalization

1. Verify device and account login on-site or via remote session
2. Provide access to:
   - Shared drives
   - Printer mappings
   - Email distribution lists
3. Send user the welcome document or IT quickstart guide
4. Log setup completion in helpdesk or internal documentation system

## Notes
- Confirm completion with hiring manager
- Update asset tracking system with device assignment
